- **Quoi** : Le rapport de risque d'Anthropic (août 2026) remonte la cote "catastrophic misalignment" de "très bas" à "bas" — incertitude globale accrue

### MCP Spec 2026-07-28 : passage au stateless
- **Quoi** : La spec MCP de juillet élimine le handshake initialize/initialized ; le protocole devient stateless avec métadonnées par requête, headers HTTP pour routing, et extensions Tasks + Apps
- **Lien** : https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
- **Pourquoi c'est important** : Changement architectural majeur — simplifie les déploiements sans état, améliore la scalabilité des agents ; les développeurs MCP doivent migrer leurs servers
- **Testable** : Oui — SDK MCP mis à jour
