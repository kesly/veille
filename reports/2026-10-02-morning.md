## 🆕 Nouveaux Outils & Produits

### Claude Code Mods (Anthropic)
- **Quoi** : Lancement des "mods" pour Claude Code — extensions TypeScript personnalisées pour modifier le comportement du CLI et de l'app desktop
- **Lien** : https://releasebot.io/updates/anthropic/claude
- **Pourquoi c'est important** : Les mods peuvent réécrire des prompts, ajouter une nouvelle UI, remplacer des fonctionnalités intégrées, intercepter des appels d'outils, approuver/refuser des permissions, redacter des secrets. Partageables comme des plugins.
- **Testable** : Oui (open-source) — TypeScript, installation via `claude plugin`

### Deepgram Flux TTS
- **Quoi** : Nouveau modèle TTS conversationnel qui conserve le contexte entre les tours (ton, rythme, registre émotionnel cohérents)
- **Lien** : https://audioxpress.com/news/deepgram-launches-flux-tts-conversation-aware-text-to-speech-model-for-voice-agents
- **Pourquoi c'est important** : Premier TTS "conversation-aware" du marché — les échanges précédents influencent la façon dont les réponses suivantes sont prononcées. Idéal pour les voice agents.
- **Testable** : Oui — via API Deepgram (payant)

### OpenAI Marketplace (beta)
- **Quoi** : Programme permettant aux clients enterprise d'appliquer leur engagement OpenAI vers des logiciels partenaires qualifiés
- **Lien** : https://community.openai.com/t/devday-2026-announcements-and-developer-resources/1402006
- **Pourquoi c'est important** : Écosystème IA unifié — OpenAI devient une plateforme de distribution pour des outils tiers via les crédits existants
- **Testable** : Oui (beta) — pour les clients enterprise éligibles

### Yellow.ai Nexus EDGE
- **Quoi** : Application desktop agent IA pour automatiser le support employé
- **Lien** : https://aiagentsdirectory.com/news/ai-agents-news-brief-october-1-2026
- **Pourquoi c'est important** : Cible le marché ITSM/HR avec un agent autonome pour résoudre les tickets employés sans intervention humaine
- **Testable** : Non — version enterprise, démo sur demande

### NVIDIA OpenShell (open-source)
- **Quoi** : Runtime sécurisé et privé pour les agents autonomes, +1 281 étoiles GitHub en une journée
- **Lien** : https://github.com/stevenko2002/agents-radar/issues/1537
- **Pourquoi c'est important** : Répond aux besoins enterprise de sécurité pour les agents — sandbox isolé, audit trails, privacy-first
- **Testable** : Oui (open-source) — disponible sur GitHub

### VoiceStudio (open-source)
- **Quoi** : Alternative open-source à ElevenLabs supportant 646 langues pour la synthèse vocale locale
- **Lien** : https://github.com/Chestnuts-Sisyphus/gittok/issues/1574
- **Pourquoi c'est important** : Privacy-preserving, local-first, aucun abonnement requis — concurrent direct d'ElevenLabs
- **Testable** : Oui (open-source, gratuit) — auto-hébergeable
