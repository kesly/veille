- **Testable** : Oui — API Anthropic et Claude.ai.

## 🆕 Nouveaux Outils & Produits

### NVIDIA NOOA — Framework agent open source (Apache 2.0)
- **Quoi** : NVIDIA Labs open-source NOOA (NVIDIA Object-Oriented Agents) : un framework Python model-agnostic où un agent = une seule classe Python. 6 capacités clés : typed I/O, pass-by-reference, code as action, boucles programmables, état explicite, APIs model-callable. Atteint 82.2 % sur SWE-bench Verified avec GPT-5.5, en utilisant moitié moins de tokens.
- **Lien** : [MarkTechPost](https://www.marktechpost.com/2026/08/07/nvidia-ai-releases-nooa-an-object-oriented-python-framework/) | [The New Stack](https://thenewstack.io/nvidia-nooa-agent-framework/)
- **Pourquoi c'est important** : Approche minimaliste radicale — zéro friction pour démarrer un agent. Contribué à l'Open Secure AI Alliance (Linux Foundation).
- **Testable** : Oui, open source — `pip install nooa` (v0.0.8, Python 3.12-3.13, statut alpha/research preview).

### MCP Spec Release Candidate (28 juillet 2026)
- **Quoi** : Release candidate majeure du Model Context Protocol : cœur stateless scalable sur HTTP standard, extension Tasks pour workflows long-running, extension MCP Apps pour UI server-rendered, auth OAuth/OIDC renforcée. Plus de 10 000 serveurs MCP référencés.
- **Lien** : [MCP Blog — 2026-07-28 RC](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/)
- **Pourquoi c'est important** : La spécification se stabilise — bon signal pour les intégrations enterprise. L'approche stateless HTTP supprime le besoin de WebSockets et simplifie l'opérationnel.
- **Testable** : Oui — spec disponible, implémentations à venir.

- **Testable** : Oui — API xAI.
