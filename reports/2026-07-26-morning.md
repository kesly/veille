# AI Watch — 2026-07-26 Matin

## 🔥 Breaking

### MCP 2026-07-28 — Spécification Release Candidate (stateless)
- **Quoi** : Le RC final de la spec MCP est disponible depuis le 23 juillet ; la spécification définitive sort **le 28 juillet** (dans 2 jours)
- **Lien** : https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/
- **Pourquoi c'est important** : Rupture majeure — le protocole devient entièrement **stateless** : suppression du handshake initialize/initialized, du Mcp-Session-Id, et des sessions persistantes. N'importe quelle requête peut désormais frapper n'importe quelle instance serveur. Les déploiements MCP peuvent tourner derrière un simple load-balancer round-robin sans sticky sessions. Le GitHub MCP Server supporte déjà le nouveau spec. Nouvelles extensions : Tasks, MCP Apps, autorisation durcie, politique de dépréciation formelle.
- **Testable** : Oui — guide de migration disponible sur https://mcpmigrate.dev/blog/mcp-spec-2026-07-28-migration-guide ; SDK Tier 1 déjà compatibles
