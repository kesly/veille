# AI Watch — 2026-10-10 Matin

## 🔥 Breaking

> Releases majeures, annonces qui changent la donne

### GPT-6 en production + Intelligent UI
- **Quoi** : OpenAI a déployé GPT-6 Sol pour les tiers payants (Oct 7) et GPT-6 Luna pour les utilisateurs Free/Go dès le 8 octobre. L'interface "Intelligent UI" intègre des éléments interactifs (calculateurs, graphes éditables, formulaires) directement dans les réponses ChatGPT.
- **Lien** : https://9to5mac.com/2026/10/07/openai-brings-gpt-6-to-chatgpt-and-debuts-intelligent-ui/
- **Pourquoi c'est important** : Premier changement radical d'interface ChatGPT depuis des années — les réponses passent du texte brut à des composants interactifs. GPT-6.1 Sol est disponible via API à `gpt-6.1-sol`.
- **Testable** : Oui — ChatGPT (payant dès maintenant, gratuit progressivement)

### Claude Haiku 5.5 & Opus 5.5 (Anthropic)
- **Quoi** : Anthropic a lancé Claude Haiku 5.5 (petit modèle haut volume, premier Haiku avec effort ajustable) et Claude Opus 5.5 (performances de Fable 5.1, -40% de coût par rapport à Opus 5) le 7 octobre.
- **Lien** : https://www.anthropic.com/news
- **Pourquoi c'est important** : Opus 5.5 offre des performances de flagship à moindre coût — une option sérieuse pour les workloads intensifs. Haiku 5.5 avec effort ajustable permet de calibrer qualité vs vitesse.
- **Testable** : Oui — via Claude.ai et l'API Anthropic (modèles `claude-haiku-5-5`, `claude-opus-5-5`)

### Mistral Large 4 Preview (1T paramètres)
- **Quoi** : Mistral a lancé une preview de son modèle le plus grand — 1 trillion de paramètres totaux, 49 milliards actifs par token (architecture MoE), avec focus cybersécurité. Les poids seront publiés en open-weight fin octobre.
- **Lien** : https://whbl.com/2026/10/06/mistral-ceo-says-new-ai-model-beats-chinese-ones-in-some-areas/
- **Pourquoi c'est important** : Plus grand modèle open-weight annoncé à ce jour. Le CEO affirme qu'il surpasse les modèles chinois sur certains domaines. API preview dispo : ~$0.68/M tokens in, $2.09/M tokens out.
- **Testable** : Oui — via API Mistral (preview)

## 🆕 Nouveaux Outils & Produits

### OpenAI DevDay 2026 — Agents API & Codex upgrades (Sept 29)
- **Quoi** : Agents API en beta publique avec computer use, mémoire persistante, multi-agents. Codex CLI reçoit voice chat, un panneau de suivi d'agents, des worktrees intégrés et l'exécution cloud. OpenAI open-source le harness Codex. Nouveau tier Ultrafast (8x plus rapide en Codex, 6x en API).
- **Lien** : https://openai.com/index/devday-2026-recap/ | https://www.infoq.com/news/2026/10/openai-devday-2026/
- **Pourquoi c'est important** : Le Codex harness open-sourcé permet à la communauté de construire des agents similaires. L'Agents API avec computer use ouvre la voie aux agents capables de piloter des interfaces.
- **Testable** : Oui — Agents API beta, Codex CLI via `npm install -g @openai/codex`

### Google Gemini Agent Universel pour Workspace (Oct 8)
- **Quoi** : Google a lancé un agent Gemini capable d'opérer dans Gmail, Drive, Docs et Calendar de façon autonome.
- **Lien** : https://www.bloomberg.com/news/articles/2026-10-08/google-launches-universal-gemini-ai-agent-for-workplace

- **Testable** : Oui — via Google Workspace (rollout en cours)

### Personal Agent Protocol v0.1 (Sierra + Meta)
- **Quoi** : Sierra et Meta ont publié un standard ouvert pour l'authentification des agents IA auprès des entreprises. Walmart et Stripe le soutiennent déjà.
- **Lien** : https://www.marketingprofs.com/opinions/2026/56118/ai-update-october-09-2026-ai-news-and-views-from-the-past-week
- **Pourquoi c'est important** : Un standard d'auth pour agents IA pourrait devenir aussi structurant qu'OAuth l'a été pour les apps. Si Walmart et Stripe adoptent, les autres retailers/fintechs vont suivre.
- **Testable** : Non (spec v0.1 — implémentation à venir)
