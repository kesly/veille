## 🔥 Breaking

### OpenAI DevDay 2026 — Plus de 20 annonces majeures
- **Quoi** : OpenAI a tenu son DevDay avec plus de 20 mises à jour couvrant ChatGPT, Codex, les modèles, les plugins, l'identité et les espaces de travail partagés
- **Lien** : https://www.infoq.com/news/2026/10/openai-devday-2026/
- **Pourquoi c'est important** : Codex passe dans le cloud (chaque tâche dispose d'un environnement isolé qui tourne même quand l'ordinateur est éteint), l'Agents API supporte désormais le computer use, et une Decisions API en preview permet classification/routage avec le modèle Luna
- **Testable** : Oui — Codex Cloud disponible dès maintenant ; GPT-6.1 Sol à $2/M tokens input ; Ultrafast tier pour Pro 500

### GPT-6.1 Sol — Performances Astra à 1/5 du prix
- **Quoi** : Nouveau modèle d'OpenAI au rapport performance/coût optimal pour le coding et le computer use, à $2/M input et $10/M output tokens
- **Lien** : https://benchlm.ai/blog/posts/openai-devday-2026
- **Pourquoi c'est important** : Performances quasi-Astra pour les tâches agentiques de coding/computer use, mais à coût drastiquement réduit. L'annonce Astra 6.1 séparée a été annulée au profit de Sol
- **Testable** : Oui — via API OpenAI immédiatement

### Google Gemini 4 Argon — IA de cybersécurité autonome
- **Quoi** : Google déploie Gemini 4 Argon en priorité aux cyber-défenseurs du programme Fairwind, capable de trouver, valider et corriger des vulnérabilités critiques de façon autonome — score de 68% sur CWE-bench v1

## 🆕 Nouveaux Outils & Produits

### Codex Cloud — Coding agent dans le cloud
- **Quoi** : OpenAI ouvre Codex à l'exécution cloud : revue de code automatique pour GitHub/GitLab, Security Cloud pour le scan de repos, CLI avec entrée vocale et interface /agents pour déléguer des tâches multiples
- **Lien** : https://community.openai.com/t/devday-2026-announcements-and-developer-resources/1402006
- **Pourquoi c'est important** : Codex devient un vrai agent asynchrone qui continue à tourner sans votre machine ; automatisation de la revue de code en CI/CD
- **Testable** : Oui — Codex Cloud disponible (plan Pro requis)

### Claude Code Mods (TypeScript)
- **Quoi** : Anthropic permet désormais des "mods" TypeScript dans Claude Code : réécriture de prompts, blocage/retry d'appels d'outils, gestion des permissions, redaction de secrets, et remplacement d'éléments d'interface dans la boucle agent
- **Lien** : https://aiweekly.co/ai-news-today/edition/2026-10-01
- **Pourquoi c'est important** : Extensibilité totale de l'agent loop sans fork — les équipes peuvent maintenant customiser Claude Code comme un framework
- **Testable** : Oui — Claude Code CLI (open source, gratuit)

### Dots by OpenAI — Agents toujours actifs
- **Quoi** : OpenAI lance Dots, des agents "always-on" qui peuvent agir proactivement en arrière-plan
- **Lien** : https://www.producthunt.com/categories/ai-agents
- **Pourquoi c'est important** : Nouvelle catégorie d'agents proactifs distincts des chatbots réactifs
- **Testable** : Oui — disponible sur Product Hunt

### MAI-Transcribe-2-Streaming (Microsoft)
- **Quoi** : Premier modèle STT streaming de Microsoft, 60 langues, détection continue de langue, premières hypothèses de transcription en ~100 ms
- **Lien** : https://aiweekly.co/ai-news-today/edition/2026-10-02
- **Pourquoi c'est important** : Latence 100ms rend la transcription temps-réel viable pour les voice agents. Rivalise directement avec Deepgram
- **Testable** : Oui — via Azure AI (payant)

### Strands Decider 2B (Amazon/Apache 2.0)
- **Quoi** : Modèle Apache 2.0 de 2B paramètres basé sur Qwen3.5, retourne des décisions plutôt que de la prose — 72% sur JevBench v19, latence médiane de 106ms sur RTX 3090
- **Lien** : https://aiweekly.co/ai-news-today/edition/2026-10-02
- **Pourquoi c'est important** : Modèle de routage/classification ultra-rapide open-source — parfait pour les orchestrateurs d'agents à faible latence
- **Testable** : Oui — open source, gratuit (Apache 2.0)

### NVIDIA OpenShell — Runtime sécurisé pour agents IA
- **Quoi** : Runtime open-source NVIDIA pour agents autonomes : binaire unique, zéro dépendances, optimisé pour les interactions agents à faible latence
- **Lien** : https://github.com/yaojiejia/agents-radar/issues/242
- **Pourquoi c'est important** : NVIDIA entre dans l'infrastructure agent côté software — isolation sécurisée sans configuration
- **Testable** : Oui — open source

### Meta Neural Band — Écriture par signaux musculaires
- **Quoi** : Meta lance le Neural Band, un bracelet sEMG qui lit les signaux musculaires du poignet pour convertir les mouvements de la main en texte, sans clavier ni téléphone
- **Lien** : https://blog.mean.ceo/ai-product-launches-news-october-2026/
- **Pourquoi c'est important** : Interface cerveau-ordinateur grand public — potentiel énorme pour l'accessibilité et les wearables
- **Testable** : Oui (disponibilité limitée)

### Claude Sonnet 5.5
- **Quoi** : Anthropic publie Sonnet 5.5 — 30% plus rapide, 30% moins cher, avec une meilleure reconnaissance de ses propres limites et une meilleure adhérence aux contraintes de sécurité

### MCP — Plus grande mise à jour depuis sa création
- **Quoi** : Le Model Context Protocol passe à une architecture stateless, renforce l'authentification, supporte les interfaces server-rendered et les tâches asynchrones longues comme extensions officielles
- **Lien** : https://venturebeat.com/infrastructure/mcp-just-got-its-biggest-update-ever-heres-what-changes-for-ai-agents
- **Pourquoi c'est important** : Les serveurs MCP sont maintenant déployables derrière des load balancers standard (Kubernetes, cloud-native) — ouvre la voie à la production at scale
- **Testable** : Oui — open standard

### GPT Image 2.5 / ChatGPT Images 2.5
- **Quoi** : Mis à jour en septembre, introduit la fonctionnalité Sketch (transformer des dessins en images IA) et réduit la latence de génération de 50%
- **Lien** : https://llm-stats.com/llm-updates
- **Pourquoi c'est important** : Génération d'images 2x plus rapide + input dessin à la main
- **Testable** : Oui — ChatGPT (payant)

### Google Gemini 3.8 Flash/Live dans AI Mode
- **Quoi** : Google déploie Gemini 3.8 Flash dans AI Mode (avec correctif pour les liens/citations), puis Gemini 3.8 Live avec des mises à jour UI pour AI Overviews
