## 🔥 Breaking

> Releases majeures, annonces qui changent la donne

### Runway Solaris — L'interface générée image par image sans code
- **Quoi** : Runway lance Solaris, le premier modèle de la catégorie « Interface World Models » : des interfaces applicatives générées en temps réel, frame par frame, sans produire une seule ligne de code
- **Lien** : [runway.com/news/research/introducing-solaris](https://runway.com/news/research/introducing-solaris)
- **Pourquoi c'est important** : Chaque clic, drag ou saisie de l'utilisateur devient un signal de conditionnement pour le world model qui génère le frame suivant. Solaris tourne sur Gen-4.5 en 720p, latence < 500 ms. Dans une étude AlphaSignal (250 participants, 7 500 jugements), Solaris est préféré à Claude Opus 5 sur le suivi d'instructions (61 %) et le comportement naturel (71 %). C'est une attaque directe sur le développement frontend traditionnel.
- **Testable** : Accès anticipé via formulaire (early access) — [runway.com](https://runway.com/news/research/introducing-solaris)

### Claudeforce — Salesforce + Anthropic : Claude nativement dans le CRM n°1
- **Quoi** : Salesforce et Anthropic ont annoncé Claudeforce le 26 août, un plugin Claude avec 37 compétences de vente pré-intégrées (préparation de réunion, santé du pipeline, revue de deals) donnant accès live aux données Salesforce directement depuis Claude
- **Lien** : [salesforce.com/news/press-releases/2026/08/26/salesforce-and-anthropic-announce-claudeforce](https://www.salesforce.com/news/press-releases/2026/08/26/salesforce-and-anthropic-announce-claudeforce/)
- **Pourquoi c'est important** : La CRM la plus utilisée en entreprise devient un MCP server de facto pour Claude. Les sales reps peuvent raisonner sur leurs pipelines et prendre des actions gouvernées sans quitter Claude. Bêta ouverte attendue en septembre 2026.
- **Testable** : Pilote sélectif déjà actif, bêta ouverte en septembre — [salesforcebreak.com/2026/08/28/claudeforce/](https://salesforcebreak.com/2026/08/28/claudeforce/)

## 🆕 Nouveaux Outils & Produits

### Deepgram Flux — Plateforme vocale context-aware (gratuite jusqu'au 12 sept.)
- **Quoi** : Deepgram lance Flux, première plateforme TTS/STT native-conversation : gestion des tours de parole, interruptions, contexte conversationnel sur toute la session
- **Lien** : [deepgram.com](https://deepgram.com/)
- **Pourquoi c'est important** : Conçu pour les voice agents, pas seulement la synthèse. Jusqu'au 12 sept. : Flux TTS gratuit avec 45 connexions streaming simultanées en US (5 en EU/AU). Fenêtre pour tester avant la monétisation.
- **Testable** : Oui, gratuit jusqu'au 12 septembre — [deepgram.com](https://deepgram.com/)

### Smallest AI Lightning V3 — TTS compact qui surpasse OpenAI et ElevenLabs
- **Quoi** : Smallest AI publie Lightning V3, un modèle TTS compact haute performance qui surpasse sur les benchmarks les modèles d'OpenAI, Cartesia et ElevenLabs
- **Lien** : [Text-to-Speech in 2026 — nextmsc.com](https://www.nextmsc.com/blogs/text-to-speech-in-2026-a-new-era-of-voice-intelligence)
- **Pourquoi c'est important** : Modèle léger et rapide, cible les applications temps réel (assistants, agents vocaux). Montre que les challengers open-weight gagnent du terrain face aux APIs propriétaires.
- **Testable** : Oui, API disponible

### Resemble AI Chatterbox-Turbo — TTS open-source ultra-léger
- **Quoi** : Architecture 350M paramètres avec décodeur one-step distillé (1 étape vs 10 en diffusion), l'un des TTS open-source les plus rapides et moins gourmands en VRAM
- **Lien** : [bentoml.com/blog/exploring-the-world-of-open-source-text-to-speech-models](https://www.bentoml.com/blog/exploring-the-world-of-open-source-text-to-speech-models)
- **Pourquoi c'est important** : Tourne sur matériel modeste. Parfait pour du déploiement on-premise ou edge.
- **Testable** : Oui, open-source

### MCP Stateless — Release candidate du nouveau standard protocolaire
- **Quoi** : La RC du 28 juillet 2026 fait passer MCP à un protocole stateless au niveau transport. MCP Apps (serveurs qui retournent des UIs interactives dans un iframe sandboxé) est maintenant officiel.
- **Lien** : [aaif.io/blog/mcp-is-growing-up](https://aaif.io/blog/mcp-is-growing-up)
- **Pourquoi c'est important** : MCP dépasse 97 millions d'installs mensuels, >10 000 serveurs publics en prod. Le passage en stateless facilite le déploiement serverless et multi-tenant. MCP Apps comble le fossé entre logique agentique et UI embarquée.
- **Testable** : Oui — RC disponible pour tests
