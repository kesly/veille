# AI Watch — 2026-08-01 Matin

## 🔥 Breaking
> Releases majeures, annonces qui changent la donne

### EU AI Act : entrée en vigueur des premières sanctions (2 août 2026)
- **Quoi** : La Commission européenne active ses pouvoirs d'enforcement sur les fournisseurs de modèles GPAI et les obligations de transparence (Article 50)
- **Lien** : https://digital-strategy.ec.europa.eu/en/news/commission-starts-enforcing-ai-act-rules-and-new-transparency-requirements-2-august
- **Pourquoi c'est important** : À partir du 2 août, tout fournisseur de GPAI (OpenAI, Anthropic, Google, Mistral…) peut être sanctionné en Europe. Les obligations de marquage du contenu synthétique (deepfakes, voix AI) s'activent aussi. Note : les systèmes à haut risque (Annexe III) sont, eux, repoussés à décembre 2027 suite au Digital Omnibus de mai 2026.
- **Testable** : Non — impact réglementaire

### DeepSeek V4-Flash-0731 : le modèle "petit budget" surclasse le modèle pro
- **Quoi** : DeepSeek publie l'officialisation de V4-Flash-0731, un MoE 284B qui bat V4-Pro-Preview sur les 9 benchmarks agentic publiés par la société
- **Lien** : https://www.caixinglobal.com/2026-08-01/deepseek-releases-official-v4-flash-model-as-chinas-ai-race-intensifies-102470292.html
- **Pourquoi c'est important** : Score 82,7 sur Terminal Bench 2.1 vs 72,1 pour V4-Pro-Preview (+14,7 %). Architecture identique à l'aperçu d'avril, gains obtenus uniquement par post-training intensif. V4-Pro annoncé pour début août. Contexte 1M tokens. Repositionne le rapport qualité/prix en faveur des modèles flash.
- **Testable** : Oui — API disponible, prix identique à la preview

### MCP 2026-07-28 : nouvelle spec stateless pour le Model Context Protocol
- **Quoi** : Anthropic finalise la spécification MCP 2026-07-28, rendant le protocole stateless et ajoutant OAuth 2.0 / OIDC natif
- **Lien** : https://blog.modelcontextprotocol.io/posts/2026-07-28/
- **Pourquoi c'est important** : MCP passe d'un protocole bidirectionnel stateful à un modèle requête/réponse — les serveurs MCP peuvent désormais tourner sur serverless et edge. Support OAuth 2.0/OIDC natif pour Entra ou Okta sans contournement. Le protocole dépasse 400 M de téléchargements mensuels de SDK (×4 cette année). Claude supporte déjà la nouvelle spec.
- **Testable** : Oui — via SDK Anthropic mis à jour
