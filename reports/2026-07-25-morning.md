## 🔥 Breaking

> Releases majeures, annonces qui changent la donne

### Claude Opus 5 — Anthropic
- **Quoi** : Nouveau flagship d'Anthropic lancé hier (24 juillet), performances comparables à Fable 5 pour moitié moins cher
- **Lien** : https://www.anthropic.com/news | https://siliconangle.com/2026/07/24/anthropic-launches-claude-opus-5-efficiency-safety-improvements/
- **Pourquoi c'est important** : $5/M tokens input / $25/M output, fenêtre 1M tokens, effort toggle (low/medium/high) pour doser la puissance de raisonnement par requête. Meilleur sur 8/13 benchmarks vs Fable 5, notamment Frontier-Bench et AutomationBench. Dispo par défaut sur Claude Max et Claude Pro. IPO Anthropic prévue dans l'année.
- **Testable** : Oui — Claude.ai (Pro/Max), API Anthropic immédiatement

### Gemini 3.6 Flash — Google DeepMind
- **Quoi** : Triple sortie Google le 21 juillet : Gemini 3.6 Flash (modèle phare), 3.5 Flash-Lite (le moins cher du marché), 3.5 Flash Cyber (cybersécurité, accès gouvernements uniquement)
- **Lien** : https://techcrunch.com/2026/07/21/google-releases-three-new-gemini-models-but-no-3-5-pro/ | https://9to5google.com/2026/07/21/gemini-3-6-flash-launch/
- **Pourquoi c'est important** : 17% moins de tokens en sortie que 3.5 Flash, prix réduit ($1.50/$7.50 per 1M i/o tokens), raisonnement configurable, support parallèle de tools. Dispo dans GitHub Copilot le même jour. Google a aussi teasé Gemini 4.
- **Testable** : Oui — Google AI Studio, API immédiatement disponible

### GPT-5.6 Sol/Terra/Luna + ChatGPT Work — OpenAI
- **Quoi** : Lancé le 9 juillet — GPT-5.6 en 3 tiers (Sol = flagship, Terra = mid-range, Luna = fast/cheap) + agent ChatGPT Work pour exécuter des tâches complètes en autonomie
- **Lien** : https://www.engadget.com/2210308/openai-rolls-out-gpt5-6-july-9/ | https://spacedaily.com/m-on-july-9-2026-openai-opened-its-most-powerful-system-yet-to-the-public-gpt-5-6-in-three-tiers-named-sol-terra-and-luna-alongside-an-agent-it-calls-chatgpt-work-built-to-carry/
- **Pourquoi c'est important** : Sol atteint 91.9% sur Terminal-Bench 2.1 (SOTA). ChatGPT Work marque un pivot vers les agents qui "font des jobs entiers" plutôt que de répondre à des questions. OpenAI a aussi confirmé une fuite de ses modèles sur Hugging Face (11-13 juillet).
- **Testable** : Oui — ChatGPT (abonnés payants), API OpenAI

## 🆕 Nouveaux Outils & Produits

### GPT-Live-1 — OpenAI (Voice full-duplex)
- **Quoi** : Modèle voix full-duplex lancé le 8 juillet — parle et écoute simultanément, remplace Advanced Voice Mode
- **Lien** : https://openai.com/index/introducing-gpt-live/ | https://techcrunch.com/2026/07/08/openai-releases-new-voice-models-for-more-natural-live-conversations/
- **Pourquoi c'est important** : Architecture à deux couches : couche légère temps-réel pour la conversation + délégation en arrière-plan à GPT-5.5 pour les tâches complexes. GPT-Live-1 (payant), GPT-Live-1 mini (gratuit). Traduit en temps réel, supporte les interruptions naturelles.
- **Testable** : Oui — ChatGPT Voice, API disponible

### Grok 4.5 + Grok Build — xAI (lancé 8 juillet)
- **Quoi** : Grok 4.5 = nouveau modèle frontier pour coding/agents co-entraîné avec Cursor. Grok Build = CLI/TUI open-source pour les coding agents
- **Lien** : https://www.digitalapplied.com/blog/grok-4-5-cursor-data-flywheel-spacex-private-beta-2026 | https://jls42.org/en/news/ia-actualites-8-jul-2026/
- **Pourquoi c'est important** : Efficacité tokens 2x supérieure pour les tâches agentiques. Grok Build est open-source et disponible sur GitHub. xAI a aussi lancé Voice Agent Builder (no-code, voix en < 2 min) + 21 nouvelles voix API.
- **Testable** : Oui — Grok Build (open-source), Grok.com pour Grok 4.5

### Seedance 2.5 API — ByteDance (live depuis le 16 juillet)
- **Quoi** : Modèle de génération vidéo 4K 30 secondes en un seul passage, sans assemblage de segments
- **Lien** : https://www.techtimes.com/articles/320683/20260716/seedance-25-api-live-bytedances-30-second-ai-video-carries-unresolved-copyright-risk.htm
- **Pourquoi c'est important** : Aucun concurrent ne génère 30 secondes continues nativement (Runway Gen-4.5, Veo 3.1, Sora 2 : max 8-15s). Supporte 50 images de référence, génération audio/vidéo unifiée. Attention : risques copyright non résolus (studios Hollywood).
- **Testable** : Oui — API BytePlus disponible (enterprise/dev)

### Robostral Navigate — Mistral (8 juillet)
- **Quoi** : Premier modèle de navigation robotique de Mistral — entrée dans la robotique
- **Lien** : https://jls42.org/en/news/ia-actualites-8-jul-2026/
- **Pourquoi c'est important** : Pivot stratégique de Mistral qui jusqu'ici se concentrait sur les LLMs. Physical AI + robotics est le nouvel eldorado du capital-risque.
- **Testable** : Non — accès limité au lancement

### MCP Specification Release Candidate (attendu 28 juillet)
- **Quoi** : La plus grande mise à jour du protocole MCP depuis son lancement — core HTTP stateless, extensions Tasks et Apps, auth OAuth/OIDC
- **Lien** : https://techcrunch.com/2026/07/20/ais-most-important-protocol-is-getting-a-little-bit-easier-to-use/ | https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/

- **Testable** : RC disponible pour commentaires avant la finale du 28 juillet
