## 🔥 Breaking

### Gemini 3.5 Transcribe — Google redéfinit le STT
- **Quoi** : Google DeepMind lance son modèle de transcription vocale le plus avancé, avec un WER de 2,6% (non-streaming) et une latence réduite de 70% vs Chirp 3
- **Lien** : [9to5Google](https://9to5google.com/2026/08/26/gemini-3-5-transcribe/) · [Blog officiel](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-5-transcribe/)
- **Pourquoi c'est important** : 85+ langues supportées, suppression automatique des "euh/ah", diarisation jusqu'à 3 locuteurs avec timestamps, déjà intégré dans Gboard Rambler et l'app Gemini sur macOS. Chrome arrive prochainement.
- **Testable** : **Oui** — Public preview via Gemini API dans Google AI Studio

### OpenAI retire le GPT officiel DALL·E — aujourd'hui
- **Quoi** : Le 30 août 2026 (aujourd'hui), OpenAI ferme l'accès au GPT officiel DALL·E dans ChatGPT
- **Lien** : [OpenAI Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)
- **Pourquoi c'est important** : Tous les flux image passent désormais par ChatGPT Images nativement. Les GPTs persos avec image generation restent actifs.
- **Testable** : **Oui** — Le changement est en cours aujourd'hui

### ChatGPT franchit le milliard d'utilisateurs hebdomadaires
- **Quoi** : OpenAI annonce 1 milliard d'utilisateurs hebdomadaires sur ChatGPT
- **Lien** : [OpenAI Newsroom](https://openai.com/news/)

- **Testable** : **Oui** — accessible sur chatgpt.com (plan gratuit)

## 🆕 Nouveaux Outils & Produits

### Meta Muse Glimmer — 30B open-source, local et agentique (10 août)
- **Quoi** : Meta Superintelligence Labs publie Muse Glimmer, 30B paramètres, Apache 2.0, optimisé pour les workflows agentiques locaux
- **Lien** : [VentureBeat](https://venturebeat.com/technology/meta-returns-to-open-source-with-muse-glimmer-an-apache-2-0-licensed-30b-parameter-ai-model-optimized-for-agents-available-now) · [HuggingFace](https://huggingface.co/meta-models/Muse-Glimmer-30B)
- **Pourquoi c'est important** : Tourne sur GPU grand public 24-32 GB VRAM en quantisation 4-bit (18-20 GB), supporte texte + image, compatible avec les frameworks d'orchestration (OpenClaw). Bat Gemma 4 31B sur la classe 30B selon Meta. Distillé depuis Muse Spark.

## 🔬 Research

### MCP 2026-07-28 : le protocole devient stateless
- **Quoi** : Nouvelle spécification MCP supprimant les sessions persistantes — chaque requête est désormais autonome, avec capacités et identité client dans les headers
- **Lien** : [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28/) · [InfoQ](https://www.infoq.com/news/2026/08/mcp-stateless-gateway/) · [Cloudflare Blog](https://blog.cloudflare.com/mcp-v2/)
- **Pourquoi c'est important** : Permet le déploiement serverless / edge, le scaling horizontal, et réduit drastiquement le coût d'infrastructure des MCP servers. SDK officiels mis à jour (TypeScript, Python, Go, C#). Cloudflare a déjà publié MCP v2 basé sur ce spec.
- **Testable** : **Oui** — specs et SDK sur modelcontextprotocol.io
