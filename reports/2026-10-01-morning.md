### Google Gemini 4 Argon
- **Quoi** : Nouveau modèle frontier de Google DeepMind annoncé le 30 septembre 2026
- **Lien** : https://techcrunch.com/2026/09/30/google-releases-gemini-4-argon-called-its-most-powerful-model-yet/
- **Pourquoi c'est important** : Limite de sortie portée à 1M tokens (vs 64K génération précédente) ; conçu pour les tâches longues en ingénierie logicielle, finance, juridique et cybersécurité. Score 77,9% sur DeepSWE v1.1. Répond à OpenAI Astra avec un positionnement "long-horizon work". Tarif : $2/M tokens en entrée, $10/M en sortie (intro)
- **Testable** : Non pour l'instant — accès limité aux partenaires cybersécurité via le programme Fairwind ; disponibilité API payante à venir sans date précise

### OpenAI DevDay 2026 — Dots, GPT-6.1 Sol, Agents API
- **Quoi** : Plus de 20 annonces lors du DevDay du 29 septembre 2026 : Dots (agents persistants), GPT-6.1 Sol, Agents API en beta publique
- **Lien** : https://www.cnbc.com/2026/09/29/openai-devday-2026-live-updates.html
- **Pourquoi c'est important** : **Dots** = agents "always-on" alimentés par GPT-6 Astra, chaque Dot a son propre cloud computer + browser, connexion à 4 000+ apps, disponibles dans ChatGPT/Slack/Teams. **GPT-6.1 Sol** = coût 5× inférieur à Astra pour le code et l'usage ordinateur, avec génération 8× plus rapide dans Codex. **Agents API** en beta publique : hébergement, mémoire, multi-agents, computer use intégrés
- **Testable** : Oui — Agents API beta publique disponible pour les développeurs ; Dots pour les abonnés Pro/Business Premium

## 🆕 Nouveaux Outils & Produits

### Deepgram Flux TTS
- **Quoi** : Modèle TTS "conversation-native" pour agents voix en temps réel (lancé août 2026)
- **Lien** : https://deepgram.com/learn/introducing-flux-tts-conversation-native-text-to-speech-for-real-time-voice-agents
- **Pourquoi c'est important** : Maintient le contexte conversationnel entre les tours (ton, rythme, registre émotionnel cohérents) contrairement aux TTS classiques qui réinitialisent chaque phrase. TTFA aussi bas que 80ms. Gratuit jusqu'au 12 sept. 2026 (offre expirée — accès payant maintenant)
- **Testable** : Oui — via l'API Deepgram (payant)

### VoiceStudio — Alternative open-source à ElevenLabs
- **Quoi** : App desktop open-source et 100% locale pour voix IA : clonage, TTS, doublage vidéo, transcription, livres audio
- **Lien** : https://github.com/debpalash/VoiceStudio
- **Pourquoi c'est important** : 50 500 stars GitHub au 1er oct. 2026 (+4 758 en 24h à son pic). 16 moteurs TTS (MLX-Audio, CosyVoice 3, OmniVoice), 11 moteurs ASR, 646 langues, clonage depuis 3-15s d'audio. FOSS (AGPL v3), zéro cloud requis — idéal pour la confidentialité et les cas offline
- **Testable** : Oui — open-source, installation locale

### xAI Grok 4.7 + Voice Transcribe 2.0
- **Quoi** : Grok 4.7 ajouté à l'API xAI + nouveau modèle STT Grok Voice Transcribe 2.0 (septembre 2026)
- **Lien** : https://releasebot.io/updates/xai
- **Pourquoi c'est important** : Grok 4.7 : 500K tokens de contexte, inputs texte + image, raisonnement flexible, endpoint US régional. Voice Transcribe 2.0 : STT multilingue avec timestamps par mot, diarisation, support multicanal, détection de tour améliorée
- **Testable** : Oui — via l'API xAI

- **Lien** : https://hackernoon.com/mcps-2026-update-makes-remote-servers-easier-to-scale
