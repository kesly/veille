### Mistral AI — Série D à €3 Milliards
- **Quoi** : Mistral lève €3B en Series D, valorisé plus de €21B — la plus grande levée de fonds d'une entreprise tech européenne privée.
- **Lien** : [TechCrunch](https://techcrunch.com/2026/09/08/mistral-raises-e3b-as-sovereign-ai-becomes-big-business/) | [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/mistral-ai-raises-3-billion-111824280.html)
- **Pourquoi c'est important** : Samsung mène avec ~€1B, rejoints par le Fonds Scaleup Europe (UE) et PSG Equity. Mistral vise $1B ARR avant fin 2026. Stratégie claire : posséder des data centers en Europe pour répondre aux exigences souveraines (armée française, Luxembourg, Airbus). La valorisation a presque doublé depuis la Series C (€11.7B).
- **Testable** : Oui — API Mistral disponible sur [mistral.ai](https://mistral.ai)

### OpenAI GPT-6 Astra — Déployé le 3 Septembre
- **Quoi** : OpenAI lance GPT-6 Astra, décrit comme le modèle IA "le plus intelligent et aligné" au monde, dépassant GPT-5.6 Sol et Claude Fable 5 sur les benchmarks majeurs.
- **Lien** : [CNBC](https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html) | [Al Jazeera](https://www.aljazeera.com/economy/2026/9/4/openai-unveils-gpt-6-astra-amid-rising-scrutiny-and-safety)
- **Pourquoi c'est important** : 1.05M tokens de contexte, 128K tokens de sortie. Pricing: $10/M input, $1/M en cache, $12.50/M cache write, $50/M output. Disponible sur ChatGPT, API, Azure et Bedrock. Focus fort sur computer use, coding, science. Nouveau : Astra embarque une tier cybersécurité gated (comme Mythos 5.1 d'Anthropic et Gemini 3.8 Flash Cyber de Google).
- **Testable** : Oui — via ChatGPT Plus ou API OpenAI

### Anthropic Claude Fable 5.1 & Mythos 5.1 — Disponibles le 1er Septembre
- **Quoi** : Anthropic lance Fable 5.1 GA avec -75% sur les cache reads ($1 → $0.25/M tokens), et Mythos 5.1 en accès restreint pour cybersécurité/sciences de la vie.
- **Lien** : [VentureBeat](https://venturebeat.com/technology/anthropics-claude-fable-5-1-and-mythos-5-1-arrive-with-a-75-cost-reduction-for-fable-cache-reads) | [MacRumors](https://www.macrumors.com/2026/09/01/anthropic-claude-fable-5-1/)
- **Pourquoi c'est important** : 25% moins cher sur les workloads typiques, jusqu'à 45% pour le travail agentique. Performances égales ou supérieures à Fable 5 et Opus 5. Mythos 5.1 = même modèle avec safeguards allégés pour usage professionnel restreint. Tendance de marché : les 3 grands labs (OpenAI, Anthropic, Google) lancent simultanément une tier cyber gated.
- **Testable** : Oui — Claude.ai (Fable 5.1) ou API Anthropic

## 🆕 Nouveaux Outils & Produits

### Deepgram Flux TTS — Voice AI Conversationnel
- **Quoi** : Deepgram lance Flux TTS, un modèle TTS natif pour agents vocaux d'entreprise, conçu pour la conversation temps réel.
- **Lien** : [Yahoo Finance](https://finance.yahoo.com/technology/ai/articles/text-speech-comes-age-deepgram-130200962.html) | [AudioXpress](https://audioxpress.com/news/deepgram-launches-flux-tts-conversation-aware-text-to-speech-model-for-voice-agents)
- **Pourquoi c'est important** : Jusqu'au 12 septembre, 45 connexions streaming simultanées gratuites (5 en EU/AU). Rejoins Flux STT dans la plateforme Voice AI de Deepgram. Concurrent direct : Deepdub Phantom Z 3.4 (150ms time-to-first-audio, 150+ langues).
- **Testable** : Oui, gratuitement jusqu'au 12 septembre via [deepgram.com](https://deepgram.com)

### Meta Muse Spark 1.3 + Muse Voice Transcribe
- **Quoi** : Meta sort Muse Spark 1.3 (LLM généraliste à ~$0.10/M tokens) le 2 sept et Muse Voice Transcribe (STT) le 1er septembre.
- **Lien** : [LLM-Stats](https://llm-stats.com/llm-updates)
- **Pourquoi c'est important** : Muse Voice Transcribe rejoint Meta AI-Transcribe-2 (Microsoft, 3 sept) dans la guerre des modèles STT du moment. Les STT 2026 vont au-delà de la transcription simple : streaming, attribution de locuteurs, détection de fin de phrase, changement de langue en live.
- **Testable** : Oui — via Meta AI API

### Gemini 3.8 Flash + Tier Cybersécurité
- **Quoi** : Google lance Gemini 3.8 Flash, son 3ème modèle Flash en 6 semaines, avec un tier cybersécurité gated pour gouvernements et grandes entreprises.
- **Lien** : [CNBC](https://www.cnbc.com/2026/09/02/google-starts-september-with-ai-momentum-after-long-losing-streak.html)
- **Pourquoi c'est important** : Enterprise passe au pay-as-you-go avec 20% de réduction sur les tokens et une option à base $0. Gemini pour Home améliore la gestion des commandes vocales mixtes (domotique + médias). Multiple code files désormais supportés dans Gemini Advanced.
- **Testable** : Oui — [gemini.google.com](https://gemini.google.com) / API Google

### Bumblebee — Scanner de Sécurité Supply Chain pour IA (Perplexity)
- **Quoi** : Perplexity lance Bumblebee, un scanner open-source qui vérifie dépendances, serveurs MCP et extensions d'éditeur pour détecter des packages suspects.
- **Lien** : [Firecrawl Blog](https://www.firecrawl.dev/blog/best-github-repos)
- **Pourquoi c'est important** : La sécurité de la supply chain IA devient un enjeu critique avec la multiplication des MCP servers (5 800+ servers community). Outil read-only, non-intrusif, en quelques secondes.
- **Testable** : Oui — open source sur GitHub
