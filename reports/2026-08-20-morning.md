## 🔥 Breaking

### Reconstruction Benchmark : les LLMs à 3-15 % sur le raisonnement scientifique
- **Quoi** : Un nouveau benchmark scientifique ("Reconstruction") révèle que les meilleurs LLMs ne récupèrent les idées de recherche qu'à 3–15 %, tandis qu'un système multi-agents atteint 42 %
- **Lien** : [TechTimes — Blind Benchmark Catches Frontier AI at Three Percent](https://www.techtimes.com/articles/324932/20260819/blind-benchmark-catches-frontier-ai-just-three-percent-research-idea-recovery.htm) | [arXiv AI list](https://arxiv.org/list/cs.AI/current)
- **Pourquoi c'est important** : Publié hier (19 août), ce benchmark est conçu pour être infaisable par mémorisation (bibliographies pré-publication, noms supprimés). Il révèle une limite structurelle réelle du raisonnement hypothétique des modèles actuels — pas un artefact de données.
- **Testable** : Non (recherche académique, pas d'interface publique)

## 🆕 Nouveaux Outils & Produits

### Cloudflare Agents Week — 20+ lancements d'infrastructure agentique
- **Quoi** : Cloudflare a lancé plus de 20 outils dédiés aux agents IA : wallets d'agents (avec paiements via `cloudflare.pay`), navigateur stateless "Kitesurf" pour agents, WebMCP (n'importe quel site devient utilisable par agent en un switch), Agent Lee (assistant naturel dans le dashboard), couche de sécurité pour trafic MCP
- **Lien** : [Cloudflare Blog — Agents Week Review](https://blog.cloudflare.com/agents-week-review-august-2026/) | [Techgenyz — Cloudflare Agents Week 2026](https://techgenyz.com/cloudflare-agents-week-2026/)
- **Pourquoi c'est important** : C'est la première offre cloud complète pensée "agents-first" : identité stable, portefeuille, réseau privé, browser, feature flags. Change le cadre pour les devs qui déploient des agents en prod.
- **Testable** : Oui — Cloudflare Workers + nouvelles APIs en developer preview

### Meta Muse Code — agent de coding terminal de Meta Superintelligence Labs
- **Quoi** : Meta lance son premier agent de coding en terminal, propulsé par le modèle Spark 1.2

### LTX-2.5 — modèle vidéo open-weight qui explose en août
- **Quoi** : LTX-2.5 génère des vidéos de 10 secondes en 6,8s grâce aux superchips Nvidia ; sa sortie en août a déclenché +28 % de contributions dans la communauté dev

- **Pourquoi c'est important** : Modèle open-weight accessible localement, performances proches du top propriétaire — combinaison rare en vidéo génération.
- **Testable** : Oui — open-source, runnable localement

### Coralogix MCP Server — intégration Olly pour Claude Code et Cursor
- **Quoi** : 5 nouveaux outils MCP (olly_ask, olly_list_chats, olly_get_artifact, etc.) permettent d'interroger Olly (observabilité IA) depuis Claude Code, Cursor ou Codex, et de récupérer logs/traces/métriques directement

- **Pourquoi c'est important** : L'observabilité devient native dans les outils de dev IA. Plus besoin de switcher vers une interface Coralogix — les agents debuggent directement.
- **Testable** : Oui (Coralogix + Claude Code/Cursor)

### Adobe Project Fast Forward — b-roll IA synchronisé dans Premiere Pro

## 🔬 Research

### Reconstruction — benchmark raisonnement scientifique (19 août)
- **Quoi** : Benchmark Swiss-tournament multi-agents sur la récupération d'idées de recherche à partir de bibliographies anonymisées. Résultat : 3–15 % en mode solo, 42 % en multi-agents
- **Lien** : [TechTimes — Blind Benchmark](https://www.techtimes.com/articles/324932/20260819/blind-benchmark-catches-frontier-ai-just-three-percent-research-idea-recovery.htm)
- **Pourquoi c'est important** : Distingue mémorisation vs. raisonnement hypothétique réel. Montre que les architectures multi-agents comblent partiellement le gap — mais pas entièrement.
- **Testable** : Non

### Saturation des benchmarks — constat de terrain (2026 AI Index)
- **Quoi** : Le rapport IA 2026 de Stanford HAI conclut que les benchmarks traditionnels (MMLU, GPQA) sont saturés et déconnectés des performances réelles
- **Lien** : [Stanford HAI — 2026 AI Index Technical Performance](https://hai.stanford.edu/ai-index/2026-ai-index-report/technical-performance)
- **Pourquoi c'est important** : La course aux scores ne mesure plus l'intelligence — ouvre un débat de fond sur ce que les modèles résolvent vraiment.
- **Testable** : Non
