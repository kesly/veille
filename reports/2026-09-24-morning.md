## 🔥 Breaking

### Anthropic : Claude découvre un système enzymatique de type CRISPR
- **Quoi** : 950 agents Claude ont traité 210 millions de tokens de données génétiques en 21h et identifié un nouveau système enzymatique (array-associated reverse transcriptases / ART) dans des bactériophages, structurellement similaire à CRISPR
- **Lien** : https://techcrunch.com/2026/09/23/anthropic-says-its-biology-lab-has-already-found-something-big/
- **Pourquoi c'est important** : Première découverte scientifique autonome par un LLM validée par Feng Zhang (pionnier de CRISPR, MIT/Broad Institute). Preuve de concept d'IA dans la recherche biologique à grande échelle
- **Testable** : Non — travail de laboratoire interne Anthropic, preprint disponible

### Nvidia acquiert Hugging Face pour 12,9 milliards de dollars
- **Quoi** : Nvidia a signé un accord définitif le 2 septembre 2026 pour acquérir Hugging Face (18M développeurs, 3M modèles, 500k datasets)
- **Lien** : https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/
- **Pourquoi c'est important** : La plus grande acquisition de l'écosystème open source IA. Nvidia s'engage à maintenir la plateforme ouverte. Clôture prévue H1 2027 sous réserve régulateur
- **Testable** : Non — transaction en cours

### OpenAI : extinction de l'API Sora aujourd'hui (24 sept.)
- **Quoi** : L'API Sora 2 (et sora-2-pro) est officiellement désactivée ce jour. L'app avait déjà fermé le 26 avril 2026
- **Lien** : https://the-decoder.com/openai-sets-two-stage-sora-shutdown-with-app-closing-april-2026-and-api-following-in-september/
- **Pourquoi c'est important** : OpenAI concentre ses ressources sur le coding et l'entreprise — GPT Image 2 devient le modèle génératif phare à la place
- **Testable** : Oui — les calls API Sora échouent dès aujourd'hui
