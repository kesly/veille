## 🔥 Breaking
> Releases majeures, annonces qui changent la donne

### OpenAI Astra — 10 problèmes mathématiques résolus
- **Quoi** : Le prochain grand modèle d'OpenAI (non encore sorti publiquement) a résolu 10 problèmes ouverts en mathématiques et théorie informatique, dont certains non résolus depuis plus de 40 ans
- **Lien** : [The Decoder](https://the-decoder.com/openai-announces-its-next-major-model-astra-by-dropping-ten-previously-unsolved-math-solutions/) | [Forbes](https://www.forbes.com/sites/jonmarkman/2026/08/03/openais-astra-solved-10-decades-old-math-problems-for-just-2000/)
- **Pourquoi c'est important** : Les preuves sont formalisées en Lean 4 (repo GitHub Apache 2.0, zéro "sorry"), coûtant ~$2 000 de compute API. Domaines couverts : géométrie haute dimension, théorie des groupes, algèbres d'opérateurs, cryptographie sur réseaux. Disprouve la conjecture de rigidité de Connes. Signale que les prochains modèles frontières atteignent un niveau de raisonnement mathématique qualitativement nouveau
- **Testable** : Non — Astra n'est pas encore disponible publiquement

### GPT-5.6 Luna — Nouveau modèle par défaut ChatGPT
- **Quoi** : OpenAI déploie GPT-5.6 Luna comme modèle par défaut pour les utilisateurs Free et Go de ChatGPT, remplaçant GPT-5.5. Ajout d'un bouton « Think » pour activer le raisonnement avancé
- **Lien** : [TechCrunch](https://techcrunch.com/2026/08/06/openai-brings-unlimited-chatgpt-text-chats-to-free-users/) | [Kraviona](https://kraviona.com/blog/latest-ai-news-august-2026)
- **Pourquoi c'est important** : ChatGPT vient de dépasser le milliard d'utilisateurs hebdomadaires. Les chats texte deviennent illimités pour tous. Réduction de prix API GPT-5.6 Sol de >20 % pour 3 mois. Note : o3 retiré de ChatGPT le 26 août
- **Testable** : Oui — ChatGPT gratuit, sans inscription supplémentaire

### Anthropic watermarke tous les outputs Claude (EU AI Act)
- **Quoi** : Depuis le 2 août 2026, tous les textes et fichiers générés par Claude intègrent un marquage machine invisible, déployé globalement pour satisfaire l'EU AI Act
- **Lien** : [Euronews](https://www.euronews.com/next/2026/08/11/eu-compliance-delivered-globally-anthropic-to-watermark-claudes-output-worldwide) | [Artificial Lawyer](https://www.artificiallawyer.com/2026/08/13/anthropic-will-embed-watermarks-in-ai-outputs/)
- **Pourquoi c'est important** : Première mise en conformité de masse avec l'AI Act européen par un grand lab. Implications légales et créatives sur tout contenu Claude généré depuis août
- **Testable** : Non (marquage invisible)

## 🧠 Mises à jour de Modèles

### Meta Muse Glimmer 30B — Open weights, tourne sur GPU grand public
- **Quoi** : Meta Superintelligence Labs publie Muse Glimmer 30B sous Apache 2.0 — modèle agent local de 30B paramètres (<20 Go en 4-bit), tourne sur un GPU 24-32 Go ou un Mac
- **Lien** : [LLM Gateway](https://llmgateway.io/timeline) | [LLM Stats](https://llm-stats.com/llm-updates)
- **Pourquoi c'est important** : Le premier modèle "agent-local" open weights de Meta. Rivalise avec Llama 3 mais positionné pour l'orchestration d'agents offline. Accessible aux devs sans cloud
- **Testable** : Oui — HuggingFace, open weights Apache 2.0

### xAI Grok 4.6 — Contexte 500k, reasoning configurable
- **Quoi** : xAI sort Grok 4.6, nouveau flagship avec fenêtre contextuelle 500 000 tokens et niveaux de raisonnement configurables (low / medium / high / xhigh). Disponible sur Microsoft Foundry

- **Testable** : Oui — xAI API, Microsoft Foundry

### LTX-2.5 — Vidéo open-weights 22B, 10 sec en 6.8 sec
- **Quoi** : LTX lance LTX-2.5, modèle world-model 22B paramètres open-weights, générant vidéo+audio synchronisés en 4K HDR depuis texte/image/clips existants. 10 sec de vidéo 720p en 6.8 secondes
- **Lien** : [VentureBeat](https://venturebeat.com/technology/ltx-2-5-can-generate-a-10-second-ai-video-from-an-image-in-just-6-8-seconds-on-nvidia-superchips-and-its-open-weights) | [LTX Blog](https://ltx.io/blog/best-open-source-video-generation-models)
- **Pourquoi c'est important** : Vitesse quasi-temps réel. Supporte multishot natif (cohérence personnage/décor). Tourne sur Mac, quantisation FP8 réduit VRAM de 40 %. 33M+ téléchargements déjà
- **Testable** : Oui — HuggingFace (poids), ComfyUI, LTX API

### MiniMax H3 — Premier modèle omni-modal open weights
- **Quoi** : MiniMax sort H3 (3 août), premier modèle open weights omni-modal générant des vidéos 2K de 4-15 sec avec audio stéréo natif
