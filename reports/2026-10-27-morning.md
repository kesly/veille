### Cursor — Computer Use en local
- **Quoi** : les agents de Cursor (IDE desktop) peuvent désormais cliquer et taper dans n'importe quelle app desktop (démo phare : iOS Simulator), pas seulement dans le navigateur ou les VM cloud. Annoncé le 23/10 selon les sources.
- **Lien** : https://alphasignal.ai/news/cursor-s-computer-use-lets-its-coding-agent-click-through-desktop-apps ; https://runtimewire.com/article/cursor-agents-computer-use-desktop-apps
- **Pourquoi c'est important** : l'agent de code peut tester lui-même les apps natives/mobiles. Un bug de sidecar est signalé sous Windows (Cursor 3.22.12).
- **Testable** : Oui — mettre à jour Cursor, @-mentionner Computer Use. Produit payant.
