## 🧠 Mises à jour de Modèles

### Gemini 3.8 Flash — meilleur modèle de raisonnement/code de Google
- **Quoi** : Troisième modèle Flash en six semaines ; focus coding et tâches agentiques ; amélioration marquée vs 3.7 Flash sur software engineering multi-étapes
- **Lien** : https://ai.google.dev/gemini-api/docs/changelog

- **Testable** : Oui — Gemini API / AI Studio (gratuit)

### Alibaba Qwen-Audio-3.1 — stack voix complet 5 modèles
- **Quoi** : TTS-Next (création audio), ASR-Next (speaker ID, timestamps, émotions), plus TTS/Realtime/ASR mis à jour. Baisse de prix : TTS −70%, Realtime −85%, ASR −95%

- **Pourquoi c'est important** : Compression tarifaire massive qui force la concurrence (ElevenLabs, Deepgram…) à s'aligner ; ASR-Next détecte les émotions et sons ambiants
- **Testable** : Oui — Alibaba Cloud API

### Meta Muse Voice Transcribe — STT de Meta (1er sept.)
- **Quoi** : Modèle de transcription de Meta avec streaming, attribution de locuteurs, biais de vocabulaire et détection de changement de langue
- **Lien** : https://www.famulor.io/blog/stt-model-benchmarks-voice-ai-production-tests-2026
