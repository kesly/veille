## 🔥 Breaking

### Claude Duet (Anthropic)
- **Quoi** : Agent proactif toujours actif (mobile iOS/Android + claude.ai) qui surveille mails/calendrier et gère planning, facturation ; demande validation avant de supprimer, payer, signer ou envoyer. Tourne sur Opus 5.5.
- **Lien** : https://kfgo.com/2026/10/21/anthropic-unveils-claude-duet-ai-agent-app/ — https://www.trendingtopics.eu/claude-duet-anthropic-ai-agent/
- **Pourquoi c'est important** : Anthropic entre dans la course aux agents « personnels » face à OpenAI Dots et Meta Muse. Annoncé ~21-22 oct (sources divergentes).
- **Testable** : Partiellement — research preview sur liste d'attente, abonnés Pro/Max US uniquement (hors Europe, hors Team/Enterprise). Payant (inclus dans l'abonnement, consomme les limites d'usage).

### OpenAI Dots (rappel, 29 sept)
- **Quoi** : Agents avec leur propre ordinateur cloud + navigateur, 4000+ apps, pilotables via ChatGPT, Slack, Teams. Basés sur GPT-6 Astra ; OpenAI aurait renoncé à sortir GPT-6.1 Astra après des tests de sécurité sur le comportement des agents.
- **Lien** : https://axios.com/2026/09/29/openai-dots-ai-assistant-devday — https://www.semafor.com/article/09/29/2026/openai-unveils-its-muse-competitor-dots
- **Pourquoi c'est important** : Contexte concurrentiel de Duet ; Meta Muse dépasserait 3M de téléchargements.
- **Testable** : Oui si abonné ChatGPT Pro / Business Premium (payant, hors EEA/CH/UK au départ).

## 🆕 Nouveaux Outils & Produits

### Grok Voice 3.0 (xAI / SpaceXAI)
- **Quoi** : Nouveau modèle speech-to-speech, lancé le 14 oct, API Voice Agent à 0,08 $/min ; ~0,4 s au premier audio ; revendique 86,9 à l'index Speech-to-Speech d'Artificial Analysis (vs 83,2 pour GPT-Live-1).
- **Lien** : https://www.voiceaispace.com/news/voice-ai-news-2026-10-18-w42
- **Pourquoi c'est important** : Prix inchangé, perf revendiquée en tête ; chiffres fournisseur non indépendants.
- **Testable** : Oui — API payante.

### GPT-Live-1.1 (OpenAI)
- **Quoi** : Mode vocal ChatGPT : nouvelles voix (FR, DE, HI, ES-MX, KO, JA), moins de « checking… ». API à venir.
- **Lien** : https://optimizesmart.com/blog/latest-voice-ai-news/
- **Pourquoi c'est important** : Amélioration multilingue du voice agent grand public.
- **Testable** : Oui dans ChatGPT (déploiement à tous).

### Drama 3 (Fish Audio)
- **Quoi** : TTS expressif pour audio scripté, poids ouverts annoncés, 83 langues.
- **Lien** : https://www.voiceaispace.com/news/voice-ai-news-2026-10-18-w42
- **Pourquoi c'est important** : TTS open-weights multilingue, utile en self-host. Source unique.
- **Testable** : Oui (open weights, à vérifier sur Hugging Face).

### Nvidia Minerva
- **Quoi** : Plateforme AIOps (GTC Berlin) unifiant télémétrie GPU/réseau/jobs dans un graphe de connaissances.
- **Lien** : https://aiweekly.co/ai-news-today
- **Pourquoi c'est important** : Outillage d'exploitation de clusters IA. Détails limités.
- **Testable** : Non (entreprise).
