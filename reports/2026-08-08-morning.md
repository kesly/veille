### MCP Protocol passe en mode stateless (spec 2026-07-28)
- **Quoi** : La nouvelle spécification MCP 2026-07-28 supprime le handshake initialize/initialized et le header Mcp-Session-Id, rendant le protocole entièrement stateless. Déjà supporté nativement par Anthropic, OpenAI et Google DeepMind.
- **Lien** : [MCP Stateless Updates – Google Developers Blog](https://developers.googleblog.com/scaling-ai-agent-infrastructure-with-the-mcp-stateless-updates/)
- **Pourquoi c'est important** : Simplification majeure du déploiement d'agents — plus besoin de gérer l'état de session côté serveur. L'écosystème MCP dépasse désormais 2 781 serveurs.
- **Testable** : Oui — SDKs Python/TypeScript MCP déjà mis à jour.

### Google Antigravity — remplaçant de Gemini CLI
- **Quoi** : Google annonce Antigravity, son assistant de code de prochaine génération qui remplace Gemini CLI et les tiers Gemini Code Assist individuels.
- **Lien** : [Best AI Coding Assistants – Shakudo](https://www.shakudo.io/blog/best-ai-coding-assistants)
- **Pourquoi c'est important** : Concurrent direct de Claude Code et Cursor — Google unifie son offre coding sous une seule marque.
- **Testable** : En déploiement progressif — à surveiller via Google AI Studio.

### Mistral Vibe — agent de travail long-running
- **Quoi** : Mistral lance Vibe, un agent autonome capable de surveiller inbox/calendrier, faire de la recherche approfondie, rédiger des livrables et gérer des PRs de code de bout en bout (web + éditeur + terminal).
- **Lien** : [Mistral Release Notes – August 2026](https://releasebot.io/updates/mistral)
- **Pourquoi c'est important** : Concurrent direct de Claude Code Agentic et Devin pour les workflows de travail multi-étapes.
- **Testable** : Oui — via Le Chat (mistral.ai).

### Mistral Shieldstral — classificateur de sécurité open-source
- **Quoi** : Mistral publie Shieldstral, un modèle de 3B paramètres multimodal (texte + images) pour la modération de contenu, avec scores calibrés, tournant sur un GPU 16GB, sous licence Apache 2.0.

- **Quoi** : Nouvelle méthode d'entraînement présentée à ICML 2026 qui entraîne les modèles à n'activer que les paramètres pertinents pour chaque tâche. Des modèles entraînés ainsi matchent les performances de modèles 3× plus grands sur les benchmarks de raisonnement.
- **Lien** : [10 Key AI Research Breakthroughs 2026](https://fueler.io/blog/key-ai-research-breakthroughs-from-so-far)
- **Pourquoi c'est important** : Réduction massive du coût d'inférence sans perte de qualité — application directe pour les déploiements edge et embarqués.
