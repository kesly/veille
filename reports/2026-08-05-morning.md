- **Testable** : Non — recherche préliminaire

### PaperBench — Benchmark de reproduction scientifique
- **Quoi** : Benchmark qui demande aux agents de recréer les contributions de papiers IA à partir du seul texte. Qwen3.8 Max (Alibaba) en tête avec **93,0 %**
- **Lien** : [BenchLM.ai](https://benchlm.ai/benchmarks/paperbench)
- **Pourquoi c'est important** : Mesure la capacité réelle de recherche autonome — bien plus difficile que MMLU (fonctionnellement saturé >88 % pour tous les modèles frontier).
- **Testable** : Oui — leaderboard public

### Nouveau spec MCP 2026-07-28 — MCP devient stateless
- **Quoi** : La spec MCP passe de bidirectionnel stateful à **request/response stateless** : handshake `initialize` supprimé, `Mcp-Session-Id` supprimé, TTL de cache obligatoire, framework d'extensions pour Tasks/Enterprise Auth/MCP Apps. Plus de 400M téléchargements SDK/mois.
- **Lien** : [MCP Blog](https://blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/) · [Digital Applied](https://www.digitalapplied.com/blog/mcp-2026-07-28-stateless-spec-agent-infrastructure-2026) · [Simon Willison](https://simonwillison.net/2026/Jul/31/stateless-mcp/)
- **Pourquoi c'est important** : Breaking change pour tous les serveurs MCP existants. Le protocole devient standard de facto : Cypress, BrowserStack, Datadog, New Relic, Honeycomb ont tous des adaptateurs MCP.
- **Testable** : Oui — spec disponible, Anthropic supporte déjà cette version dans Claude Code
