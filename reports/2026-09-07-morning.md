## 🔥 Breaking
> Releases majeures, annonces qui changent la donne

### GPT-6 Astra — OpenAI
- **Quoi** : Nouveau flagship d'OpenAI pour le computer use, la navigation web, le software engineering et la recherche scientifique
- **Lien** : https://www.cnbc.com/2026/09/03/open-ai-astra-gpt-6-cyber.html
- **Pourquoi c'est important** : Surpasse GPT-5.6 Sol et Claude Fable 5 sur les benchmarks ; scores parfaits ou quasi-parfaits en raisonnement. Contexte 1,05M tokens, sortie 128K. Tarif : $10/$1 cached/$50 /1M tokens. Disponible ChatGPT, API, Azure et Bedrock avec "Codex context preservation". Greg Brockman a mis l'accent sur la sécurité : "AI can only benefit people when safety is a core part of it."
- **Testable** : Oui — via ChatGPT Plus/Pro ou l'API OpenAI

### Claude Fable 5.1 + Claude Mythos 5.1 — Anthropic
- **Quoi** : Double release Anthropic du 1er septembre — deux modèles identiques avec des niveaux de garde-fous différents pour coding, knowledge work et recherche scientifique
- **Lien** : https://claudelog.com/claude-news/
- **Pourquoi c'est important** : Mythos 5.1 est la variante à garde-fous réduits pour les cas d'usage scientifiques et entreprise avancés. Simultanément, Anthropic annonce les **Enterprise Frontier Safeguards (EFS)** : zero data retention + détection des abus stockée dans l'infra cloud du client. Supporte Claude Code, Claude Enterprise, Bedrock, Google Agent Platform, Microsoft Foundry.
- **Testable** : Oui — via claude.ai ou l'API Anthropic (ID : `claude-fable-5-1`)

## 🆕 Nouveaux Outils & Produits

### Deepgram Flux TTS — Gratuit jusqu'au 12 septembre
- **Quoi** : Premier TTS "conversation-native" — adapte le rythme, l'emphase et le registre émotionnel au contexte conversationnel en temps réel
- **Lien** : https://deepgram.com/product/text-to-speech/flux
- **Pourquoi c'est important** : Intégrations natives : Vapi, Pipecat, LiveKit, Jambonz, Cloudflare. 45 connexions streaming simultanées offertes (5 EU/AU) jusqu'au 12/09. Flux Multilingual (STT) sorti en avril 2026 est déjà GA.
- **Testable** : Oui, gratuit — https://deepgram.com/product/text-to-speech/flux (jusqu'au 12/09)

### AI Agents Listing — Premier annuaire unifié Agents + MCP
- **Quoi** : Lancé le 6 septembre, premier répertoire cross-indexant agents IA, serveurs MCP et agent skills avec un endpoint MCP dédié pour les agents
- **Lien** : https://www.openpr.com/news/4623126/ai-agents-listing-launches-as-the-first-directory-to-index-ai
- **Pourquoi c'est important** : Listing gratuit, validé manuellement. Le répertoire lui-même est consommable par des agents via MCP — un méta-agent qui peut trouver ses propres outils.
- **Testable** : Oui — listing gratuit, endpoint MCP accessible

### Google Antigravity — Successeur de Gemini CLI
- **Quoi** : Nouvel assistant de coding IA annoncé à Google I/O mai 2026, remplace Gemini CLI et Gemini Code Assist, construit en Go, workflows asynchrones en arrière-plan
- **Lien** : https://checkmarx.com/learn/ai-security/top-12-ai-developer-tools-in-2026-for-security-coding-and-quality/
- **Pourquoi c'est important** : Architecture unifiée entre CLI, desktop app et IDE. Alternative sérieuse à Claude Code et Cursor pour les équipes déjà dans l'écosystème Google.
- **Testable** : Oui — disponible pour développeurs Google

### Bumblebee — Scanner de supply chain pour IA (Perplexity AI)
- **Quoi** : Outil open-source read-only qui scanne dépendances, serveurs MCP et extensions éditeur pour détecter des paquets suspects en secondes
- **Lien** : https://ossinsight.io/trending/ai
- **Pourquoi c'est important** : Répond aux risques croissants de compromission des chaînes MCP et des extensions VS Code. Utile pour tout développeur utilisant des MCP tiers.
- **Testable** : Oui — open-source

## 🔬 Research

### AIRS-Bench — Benchmark pour agents de recherche scientifique
- **Quoi** : Suite d'évaluation publiée sur arXiv en septembre 2026, ciblant les agents IA dans le cycle de vie complet de la recherche
- **Lien** : https://arxiv.org/pdf/2606.07462
- **Pourquoi c'est important** : MMLU est saturé au-dessus de 88% pour les modèles frontière — les différences de score sont devenues statistiquement non significatives. AIRS-Bench ouvre une nouvelle dimension d'évaluation : capacité à générer des hypothèses, conduire des expériences et vérifier des résultats.
- **Testable** : Oui — papier open access sur arXiv

### Mémoire des agents IA — Rapport d'état 2026
- **Quoi** : Rapport mem0.ai sur l'état de la mémoire des agents IA avec benchmarks LoCoMo, LongMemEval et BEAM
- **Lien** : https://mem0.ai/blog/state-of-ai-agent-memory-2026
- **Pourquoi c'est important** : La mémoire agent est désormais un composant architectural de première classe. Les nouvelles approches combinent similarité sémantique, BM25 et entity matching dans un score fusionné.
- **Testable** : Non (rapport)
