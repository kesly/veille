## 🔥 Breaking

### Mistral Large 4 — 1 trillion de paramètres, open-weight
- **Quoi** : Mistral lance en preview son modèle phare, un MoE de ~1T paramètres (49B actifs par token), natif multimodal, ciblant la cybersécurité et les usages agentiques
- **Lien** : https://thenextweb.com/news/mistral-releases-large-4-a-1-trillion-parameter-open-weight-ai-model
- **Pourquoi c'est important** : Premier modèle open-weight de cette taille venant d'Europe, conçu pour concurrencer les modèles frontier fermés et les modèles chinois. Les poids seront libérés fin octobre (~27 oct). API en preview dès maintenant.
- **Testable** : Oui — API Mistral en preview : $0.68/M tokens input, $2.09/M output (tarif réduit preview)

### Claude Haiku 5.5 — réduction de prix 90% pour les petits volumes
- **Quoi** : Anthropic lance Haiku 5.5 le 7 octobre, avec un prix de $0.10/M tokens input (sous 100k tokens), soit −90% vs les concurrents directs
- **Lien** : https://venturebeat.com/technology/anthropic-launches-claude-haiku-5-5-with-90-api-price-reduction-matching-gpt-6-luna
- **Pourquoi c'est important** : Premier Haiku avec contrôle d'effort (effort controls), support computer use et browser use en bêta. Conçu comme sous-agent au sein de workflows Claude Opus 5.5 / Sonnet 5.5. Disponible dès maintenant sur AWS, GCP, Azure et l'API Anthropic.
- **Testable** : Oui — `claude-haiku-5-5` sur l'API Anthropic, claude.ai

### UndoBench — benchmark de récupération pour agents avec outils
- **Quoi** : Nouveau benchmark qui mesure la capacité des agents à se remettre d'une erreur dans un workflow, séparément de leur capacité à compléter la tâche
- **Lien** : https://arxiv.org/list/cs.AI/current
- **Pourquoi c'est important** : Constat clé : les agents capables de compléter des workflows échouent souvent à se remettre proprement d'une faute. Essentiel pour l'évaluation de la fiabilité des agents en production.
