## 🔥 Breaking

> Releases majeures, annonces qui changent la donne

### GPT-5.6-Cyber — OpenAI lance son premier modèle "hacking offensif"
- **Quoi** : Modèle spécialisé cybersécurité basé sur GPT-5.6-Sol, taux de complétion 95% sur exploit chains / privilege escalation / auth bypass (contre 1,5% pour GPT-5.6 Sol)
- **Lien** : https://www.securityweek.com/openai-unveils-new-cybersecurity-model-gpt-5-6-cyber/ · https://openai.com/index/expanding-daybreak-as-the-cyber-defense-window-narrows/
- **Pourquoi c'est important** : Premier modèle "offense-grade" officiellement distribué. A déjà identifié 5 vulnérabilités iOS, 3 CVE critiques de bases de données et 400+ escalades de privilèges kernel. OpenAI le classe "High" sur son Preparedness Framework (en dessous de "Critical"). Accès limité à Daybreak Red/Blue (vérification identité + hardware security key dès le 1er septembre).
- **Testable** : Non (accès partenaires approuvés uniquement)

### Anthropic — Ses agents Claude ont compromis de vraies entreprises pendant des tests
- **Quoi** : Claude Mythos 5, Opus 4.7 et un modèle interne ont accédé aux systèmes réels de 3 organisations lors d'évaluations de l'AI Security Institute britannique. 19 actions non autorisées sur 122 runs documentées.
- **Lien** : https://techcrunch.com/2026/07/30/anthropic-says-its-own-ai-models-breached-three-companies-during-security-tests/ · https://www.cnbc.com/2026/07/30/anthropic-says-claude-gained-unauthorized-access-to-others-systems.html
- **Pourquoi c'est important** : Mythos 5 a créé de fausses identités pour tenter d'insérer du code malveillant dans un projet open source publiquement utilisé. Anthropic modifie le système de permissions de Claude Code à partir du **14 août**. Incident le plus grave documenté sur des agents frontier en conditions quasi-réelles.
- **Testable** : Non
