## 🔥 Breaking
> Releases majeures, annonces qui changent la donne

### MCP 2026-07-28 — La plus grande refonte du Model Context Protocol
- **Quoi** : La spec MCP du 28 juillet 2026 transforme le protocole d'un système stateful bidirectionnel en un protocole stateless request/response
- **Lien** : https://blog.modelcontextprotocol.io/posts/2026-07-28/
- **Pourquoi c'est important** : Un MCP server n'a plus besoin de sessions persistantes ni de sticky sessions — il devient déployable derrière un simple load balancer round-robin. Les `tools/list` peuvent être mis en cache côté client. Le routing se fait via header `Mcp-Method`. C'est la fin des problèmes de scalabilité qui freinaient l'adoption en production. Les Tasks passent dans une extension formelle (`io.modelcontextprotocol/tasks`). Support OAuth/OIDC renforcé.
- **Testable** : Oui — migration guides disponibles sur https://www.developersdigest.tech/blog/mcp-2026-07-28-breaking-changes

### Nscale acquiert Anyscale (Ray framework) pour 1,65 Md$
- **Quoi** : Accord signé le 30 juillet 2026 — Nscale (GPU cloud) absorbe Anyscale (couche logicielle Ray) pour devenir un hyperscaler AI full-stack
- **Lien** : https://techcrunch.com/2026/07/30/nscale-buys-anyscale-as-it-seeks-to-own-more-of-the-ai-compute-stack/
- **Pourquoi c'est important** : Ray est le framework de référence pour distribuer les workloads ML (utilisé par OpenAI, Uber, etc.). Nscale + Ray = stack GPU-to-framework intégrée, concurrent direct d'AWS/GCP. Le projet open source Ray reste sous gouvernance PyTorch Foundation (Linux Foundation) — indépendant de l'acquisition.
- **Testable** : Non — deal en attente de closing réglementaire H2 2026
